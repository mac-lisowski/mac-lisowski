## Featured projects

### Node.js and TypeScript

#### [node-monorepo-boilerplate](https://github.com/MiviaLabs/node-monorepo-boilerplate)

An Nx and pnpm monorepo starter with NestJS API, Next.js web and admin apps, and an Expo mobile app. The API includes CQRS, multi-tenant guards, and a transactional outbox with Kafka dead-letter handling and replay. Shared packages cover auth, encryption, queues, storage, policy, and observability. The local Docker Compose stack includes PostgreSQL, Redis, Kafka, MinIO, and MailHog.

### Python

#### [project-taipan](https://github.com/mac-lisowski/project-taipan)

A Python monorepo for learning and building with the Python ecosystem, managed with uv workspaces. It includes a FastAPI service, a Typer CLI, shared Python packages, and a Next.js frontend. PostgreSQL with pgvector and Redis support the API and web app; Alembic manages database migrations.
